⚠ Cảnh báo lớn nhất 2026

Cache TTL silently drop 1h → 5 phút (2026-03). Idle > 5 phút = cache chết. Discipline: đừng để session idle quá lâu.

03 · Tư duy

10 mindset shift — đừng để Claude làm thui chột nghề

01
Doing → Directing30% spec + 50% review + 20% intervene. Ngừng cố làm typist.
02
Đọc code/output thành core skillTest "narrate-back": kể lại được từng block làm gì → mới accept.
03
Trust-but-verify70% problem (Addy Osmani). Review output mệt hơn review work của con người.
04
Skill atrophy mitigationNo-AI sprint định kỳ. Junior 6 tháng đầu hạn chế Claude cho fundamentals.
05
Spec-first thinkingBrief 500-1500 từ với constraint, ví dụ, anti-pattern. Brief <200 từ — chưa đủ.
06
Blast radius mindsetKhông bao giờ Claude trực tiếp đụng prod. Staging clone → verify → apply.
07
Override khi Claude bịaSố liệu SEO phải trace về MCP source thực. Plausible-but-wrong là failure mode nguy hiểm nhất.
08
Learning loop hàng ngàyMentor Loop (Fowler): goal nhỏ → plan → check → reflect. Đọc Claude diff = reverse mentorship.
09
Non-dev cần học gìTerminal · git · JSON/YAML · Markdown · prompt design. KHÔNG cần Python/JS.
10
Không thành button-pusherTreat Claude như "OS for knowledge work", không "magic answer machine".

Anti-pattern: vòng xoáy thành button-pusher

Bước 1

Over-trust

Accept vì "có vẻ đúng".

Bước 2

Learned helplessness

Copy-paste error vào Claude.

Bước 3

Prompt-hoarding

500 prompt thay vì xây judgment.

Bước 4

Button-pusher

Claude xuống → tê liệt.

Onboarding 4 tuần — non-dev marketer

Week 01
Terminal cơ bản
cd · ls · cat · grep · ENV var.
Week 02
Git cơ bản
commit · diff · revert · push.
Week 03
JSON/YAML/Markdown
Đọc & sửa được. Recognize TS/Python.
Week 04
Prompt + plan mode
Spec/brief tốt. Slash command. CLAUDE.md.

5 câu tự kiểm tra hàng tuần

  • Narrate-back được output Claude? Không → button-push.
  • Verify ≥1 con số / fact / citation? Không → đặt cược danh tiếng client.
  • Làm 1 task without Claude? Không → cẩn thận skill atrophy.
  • Cải thiện 1 spec/brief? Brief code-quality nâng dần.
  • Review 1 hành động blast-radius? Một câu "không" = một rủi ro thực.
