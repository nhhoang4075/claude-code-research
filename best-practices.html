⚠ Cảnh báo lớn nhất 2026

Cache TTL 5 phút mặc định (1h khi dùng option extended). Cache write 1.25× input · cache read 0.1× input → reuse cache rẻ hơn 90%. Idle > 5 phút = cache chết.

03 · Tư duy

10 mindset shift — đừng để Claude làm thui chột nghề

01
Doing → Directing
30% spec + 50% review + 20% intervene. Ngừng cố làm typist.
Strong Karpathy verbatim Jan 2026: "80% manual+autocomplete → 80% agent coding... biggest change in 2 decades of programming". x.com/karpathy/status/2015883857489522876
02
Đọc code thành core skill
Test "narrate-back": kể lại được từng block làm gì → mới accept.
Medium SO 2025: 61.3% want to fully understand their code · 76% won't trust AI for deployment. Pattern real, magnitude anecdotal. survey.stackoverflow.co/2025/ai/
03
Trust-but-verify
70% problem (Osmani). Review output mệt hơn review work của con người.
Strong Osmani: favorable views AI coding 70% → 60% trong 2 năm · ~30% report little/no trust. Vectara: Sonnet 4.5 >10% hallucination (summarization). addyo.substack.com/p/the-70-problem-hard-truths-about
04
Skill atrophy mitigation
No-AI sprint định kỳ. Junior 6 tháng đầu hạn chế Claude cho fundamentals.
Strong Anthropic RCT n=52 Feb 2026: AI users 17% lower comprehension. Full-delegate <40%, explanation-seeking >65%. anthropic.com/research/AI-assistance-coding-skills
05
Spec-first thinking
Brief 500-1500 từ với constraint, ví dụ, anti-pattern. Brief <200 từ chưa đủ.
Weak Practitioner consensus only. Cherny: plan mode + feedback loop là core. Không có controlled study về "brief quality → output quality" correlation. code.claude.com/docs/en/best-practices
06
Blast radius mindset
Không bao giờ Claude trực tiếp đụng prod. Staging → verify → apply.
Strong PocketOS: Claude Opus 4.6 deleted prod DB trong 9 giây, including backups. Replit Jul 2025: deleted DB during code freeze, fabricated 4,000 fake users. blog.railway.com/p/your-ai-wants-to-nuke-your-database
07
Override khi Claude bịa
Số liệu SEO phải trace về MCP source thực.
Strong METR RCT Jul 2025: experienced devs 19% slower với AI tools, despite believing 20-24% faster. Vectara: Sonnet 4.5 >10% hallucination. arxiv.org/abs/2507.09089
08
Learning loop hàng ngày
Mentor Loop (Fowler): goal nhỏ → plan → check → reflect tradeoff.
Strong Fowler verbatim: "don't shortcut the learning loop", LLMs là "ultimate Maintenance Cliff". Anthropic RCT confirms: iterative debug → 17% lower comprehension. martinfowler.com/articles/llm-learning-loop.html
09
Non-dev cần học gì
Terminal · git · JSON/YAML · Markdown · prompt design. KHÔNG cần Python/JS.
Medium "How Anthropic Teams Use Claude Code" PDF: "lawyers built phone tree systems, marketers generated hundreds of ad variations, data scientists created visualizations without knowing JavaScript". anthropic.com/.../How Anthropic teams use Claude Code (PDF)

Week 04
Prompt + plan mode
Spec/brief tốt. Slash command. CLAUDE.md.

5 câu tự kiểm tra hàng tuần

  • Narrate-back được output Claude? Không → button-push.
  • Verify ≥1 con số / fact / citation? Không → đặt cược danh tiếng client.
  • Làm 1 task without Claude? Không → cẩn thận skill atrophy.
  • Cải thiện 1 spec/brief? Brief code-quality nâng dần.
  • Review 1 hành động blast-radius? Một câu "không" = một rủi ro thực.
04 · Counter-evidence

Findings contradict conventional wisdom

Adoption ≠ satisfaction. Productivity câu chuyện không đơn giản. Đáng surface explicitly để SEONGON tránh "AI hype trap" trong leadership deck.

⚑ Strongest counter-data

METR RCT — devs 19% chậm hơn với AI

Peer-reviewed RCT Jul 2025: experienced OSS dev dùng AI tool 19% slower trong khi tin rằng mình nhanh hơn 20-24%. Perception gap dramatic.

arxiv.org/abs/2507.09089

Update Feb 2026: METR pause late-2025 follow-up vì quá nhiều dev refuse to participate without AI — productivity question giờ confounded.

Anthropic's own RCT

17% lower comprehension

Anthropic skill-formation RCT n=52 junior engineer Feb 2026. AI-using group 17% lower comprehension. Full-delegation <40% quiz · explanation-seeking >65%.

anthropic.com/research/AI-assistance-coding-skills

Anthropic itself publishes data warning AI assistance lower comprehension cho learner.

Adoption ≠ satisfaction

SO 2025 — adoption up, trust down

Stack Overflow 2025: AI tool adoption 76% → 84%. Cùng năm trust drop 40% → 29%. 3% "high trust". 46% actively distrust. 66% report "almost right but not quite". 45% lose significant time debugging AI code.

survey.stackoverflow.co/2025/ai/

Delivery stability

AI-gen code: −7.2% delivery stability

Harness research (via atomicrobot.com): AI sped code creation NHƯNG decrease delivery stability 7.2%. Single industry source — verify primary trước cite.

atomicrobot.com (verify primary)

⚑ Implication cho SEONGON pitch

Adoption Claude Code không tự động → productivity gain. Phải kèm: (1) verification loop (P3), (2) review discipline (P6), (3) skill atrophy mitigation (M4), (4) blast radius guardrail (M6). Skip những điều này → đi vào "vibe coding hangover".
