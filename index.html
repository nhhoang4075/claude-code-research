7 chiều scoring (1-5 each)

  • AUTH · Authority — AgriciDaniel handle = 2. Anthropic primary = 5.
  • SPEC · Specificity — exact metric vs vague enthusiasm.
  • INDP · Independence — vendor = 1, observer = 4.
  • RCNT · Recency — 2026 = 5, ≤ 2024 = 1.
  • VRFY · Verifiability — open-source/dataset = 5.
  • MTCH · SEONGON service match — direct = 5.
  • ADOPT · Adoption — 3,000+ stars / canonical = 5.
