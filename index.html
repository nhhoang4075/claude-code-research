Three-tier adoption shape

Adoption is not all-staff. Different roles need different tooling and different access. The leverage compounds when Tier 2 builds skills that Tiers 3 reuse.

Tier 1 · ~5 people
Engineering / AI team
Tooling: Claude Code CLI + API · Cost: API-based

Builds SEONGON-internal infrastructure: shared skill repo, internal MCP servers, training materials, governance tooling. Already exists; extends to internal infra builder role.

Tier 2 · ~10–20 people · highest leverage
Senior power users — 1–2 leads per discipline
Tooling: Claude Code CLI + IDE · Cost: Team plan + meaningful API

Builds the agency's Claude Skills as Git-versioned .md files. QA's outputs from Tier 3. Localizes open-source skills to Vietnamese-market specifics. This is where compounding agency IP gets created.

Tier 3 · ~100+ people
Production marketers — ad ops, junior SEOs, content writers, AMs
Tooling: Claude.ai Team plan + Claude Cowork · Cost: per-seat

Consume the skills Tier 2 builds. Don't write new skills; run existing ones, request fixes when outputs miss. Terminal/CLI is a graduation path, not a default.

Strategic upside · beyond efficiency

GEO is a service line, not a side note.

Generative Engine Optimization — getting brands to surface inside Claude / ChatGPT / Perplexity / Gemini / Google AI Overviews — appears as a first-class capability in every serious SEO Claude Code resource we reviewed. Few Vietnamese agencies have productized GEO yet. SEONGON has a first-mover window.

Defensive
Search-traffic erosion

AI Overviews and ChatGPT capture queries upstream of Google's blue links. SEO retainer CTR metrics will face downward pressure within 12–24 months.

Offensive
Productize GEO consulting

Use the open-source GEO skill libraries (claude-seo's seo-geo subagent, aaron-he-zhu's CORE-EEAT + CITE frameworks) as the technical base.

Adjacent service
AI Search Visibility Dashboard

Recurring deliverable per client; tracks brand presence across Claude/ChatGPT/Perplexity/Gemini/AIO. 15-min build per SEO Francisco recipe.

Open questions for SEONGON-internal phase

These need internal data, not desk research. They gate the move from research pack to formal proposal.

  1. Q1 · Baseline
    Current per-account fulfillment hours by service line

    Without this, the time-savings projection is industry-average, not SEONGON-specific.

  2. Q2 · Stack
    Client mix by martech stack (HubSpot vs. Salesforce vs. nothing)

    Drives the integration build order for marketing-ops automation.

  3. Q3 · Content
    Vietnamese AI-content detector landscape

    Drives anti-slop layer design. Need to know which detectors clients use and at what thresholds.

  4. Q4 · Demand
    Existing-client appetite for GEO consulting upsell

    Drives whether GEO becomes a productized service in 90 days vs. 12 months.

  5. Q5 · Capacity
    Senior time available for skill-building vs. running current accounts

    Drives realistic pilot timeline. Tier 2 work is meaningful upfront investment.
