The strongest single precedent

Anthropic's own Growth Marketing team is non-technical — and runs SEONGON's exact channel mix.

From How Anthropic teams use Claude Code[1], their internal-team interview report. The precedent matters because Anthropic owns the tool and has no incentive to over-promise its usefulness in an internal report.

Anthropic Growth Marketing team — documented profile
  • Team size: "non-technical team of one"
  • Channels: paid search · paid social · mobile app stores · email marketing · SEO
  • Workflow #1: Automated Google Ads creative generation with sub-agents (one for headlines, one for descriptions)
  • Workflow #2: Figma plugin generates 100 ad variations per batch in 0.5 s — 10× creative output
  • Workflow #3: In-house Meta Ads MCP server for campaign analytics inside Claude Desktop
  • Workflow #4: Memory system that logs hypotheses across iterations — self-improving testing framework
  • Reported impact: ad copy 2 h → 15 min · "operates like a larger team" · strategic focus shift from manual execution to system-building
Implication for SEONGON: the question isn't "can a marketer run Claude Code?" — that's been answered in production. The question is operating-model design across SEONGON's 100+ specialists.

Three-tier adoption shape

Adoption is not all-staff. Different roles need different tooling and different access. The leverage compounds when Tier 2 builds skills that Tier 3 reuses.

Tier 1 · ~5 people
Engineering / AI team
Tooling: Claude Code CLI + API · Cost: API-based
Builds SEONGON-internal infrastructure: shared skill repo, internal MCP servers, training materials, governance tooling. Already exists; extends to internal infra builder role.
Tier 2 · ~10–20 people · highest leverage
Senior power users — 1–2 leads per discipline
Tooling: Claude Code CLI + IDE · Cost: Team plan + meaningful API
Builds the agency's Claude Skills as Git-versioned .md files. QA's outputs from Tier 3. Localizes open-source skills to Vietnamese-market specifics. This is where compounding agency IP gets created.
Tier 3 · ~100+ people
Production marketers — ad ops, junior SEOs, content writers, AMs
Tooling: Claude.ai Team plan + Claude Cowork · Cost: per-seat
Consume the skills Tier 2 builds. Don't write new skills; run existing ones, request fixes when outputs miss. Terminal/CLI is a graduation path, not a default.

GEO is a service line, not a side note.

Generative Engine Optimization — getting brands to surface inside Claude / ChatGPT / Perplexity / Gemini / Google AI Overviews — appears as a first-class capability in every serious SEO Claude Code resource we reviewed[5][7][19]. Few Vietnamese agencies have productized GEO yet. SEONGON has a first-mover window.

Defensive
Search-traffic erosion

AI Overviews and ChatGPT capture queries upstream of Google's blue links. SEO retainer CTR metrics will face downward pressure within 12–24 months.

Offensive
Productize GEO consulting

Use the open-source GEO skill libraries (claude-seo's seo-geo subagent[5], aaron-he-zhu's CORE-EEAT + CITE frameworks[7]) as the technical base.

Adjacent service
AI Search Visibility Dashboard

Recurring deliverable per client; tracks brand presence across Claude/ChatGPT/Perplexity/Gemini/AIO[31].

Brand-as-Skill

Package each client's brand guidelines as a reusable Claude Skill[30] — sticky deliverable that recurs across the client lifecycle.

Open questions for SEONGON-internal phase

These need internal data, not desk research. They gate the move from research pack to formal proposal.

  1. Q1 · Baseline
    Current per-account fulfillment hours by service line

    Without this, the time-savings projection is industry-average, not SEONGON-specific.

  2. Q2 · Stack
    Client mix by martech stack (HubSpot vs. Salesforce vs. nothing)

    Drives the integration build order for marketing-ops automation.

  3. Q3 · Content
    Vietnamese AI-content detector landscape

    Drives anti-slop layer design. Need to know which detectors clients use and at what thresholds.

  4. Q4 · Demand
    Existing-client appetite for GEO consulting upsell

    Drives whether GEO becomes a productized service in 90 days vs. 12 months.

  5. Q5 · Capacity
    Senior time available for skill-building vs. running current accounts

    Drives realistic pilot timeline. Tier 2 work is meaningful upfront investment.
