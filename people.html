Parallelism spectrum — disagreement is real
Số lượng agent chạy đồng thời mà mỗi luminary thực hành. Không có industry consensus.

5 pattern recurring across all 8 luminary

01
Plan mode is consensusCherny, Ronacher, Hashimoto, Karpathy đều start với planning trước generation. Cherny: "never a line of code until plan approved" — single most repeated practice. Even Ronacher's "no plan mode" thực ra là custom plan-as-markdown.
02
Verification loop > raw speedCherny "2-3× quality from feedback loop", Yang "review every line", Hashimoto "QA while agent codes", Yegge "plan-implement-review-test loop". Tests, type checker, browser MCP — anything machine-checkable là moat.
03
Parallelism real but disputedCherny (10-15), Yegge (20-30), Hashimoto (always-on bg), Litt (kanban-managed) lean heavy. Yang + Litt push back: comprehension và surgical focus matter more. Không có consensus.
04
Skills + CLAUDE.md beat MCPWillison + Ronacher cùng public downgrade MCP. Skills (post-Oct 2025) và well-tuned CLAUDE.md (Karpathy, Cherny team file) là cái people thực sự dùng day-to-day. SEONGON: invest first vào CLAUDE.md + skills, treat MCP optional.
05
Senior nhất là người opinionated nhất về limitsKarpathy nanochat retreat, Yang "read every line", Litt surgeon framing — endorsement mạnh nhất luôn kèm explicit limits. More credible signal than uniform hype: những người này đã nghĩ về where it breaks.

6 pattern recurring across non-engineer leaders

01
Personal-infrastructure glueMullenweg's Sonos/calendar/PDF utilities, Lenny's storage cleanup + Sheet randomizer, Newton's writing-archive search. Common thread: "tools too small to justify hiring engineer for, but too annoying to do manually." Claude Code wins over ChatGPT vì act on local files.
02
Personal websites + brand surfaceNewton replaced Squarespace (saved $200/yr). Levels rebuilt pieter.com như 3D Three.js environment. Non-engineer leader đang kill SaaS subscription bằng weekend Claude Code project.
03
Strategy/coaching surface, không phải codeLavingia 9 slash command for business decision. Tan gstack roles (CEO/Designer/QA). Claude Code dùng như structured conversation partner — value là persistent skill definition + filesystem context, không phải generated code.
04
Run-it-headless infrastructureLevels VPS pattern, Srinivas Perplexity Computer orchestration. Leaders treat Claude Code như background worker on server, không phải chat tab. Biggest divergence từ ChatGPT-style use.
05
"Tools, not text"Casey Newton's framing — "LLMs' power to generate tools" — recurs implicitly trong Mullenweg, Tan, Lavingia. Non-engineer dùng Claude Code để manufacture small bespoke applications, không phải draft documents.
06
Skill pack as portable artifactTan + Lavingia ship public skill repo. Trong leaders, "publish your CLAUDE.md / skills" trở thành form of thought leadership distinct từ blog or podcast. SEONGON: cân nhắc publish methodology như public skill pack.
Implication cho SEONGON leadership

Use case agency-leadership không phải "Claude Code viết social post". Mà là (a) personal CLI cho ops + personal-data task của lãnh đạo (Mullenweg/Lenny pattern), và (b) skill pack codify SEONGON methodology — positioning framework, audit checklist, briefing template — staff non-technical invoke như slash command (Tan/Lavingia pattern). Cái này có thể trở thành thought-leadership artifact distinct từ blog/podcast.

⚑ Null #1 · cơ hội first-mover
Không có Vietnamese C-level public mention

SEONGON sẽ là first-mover nếu publish thought-leadership Vietnamese-market về adoption — competitive moat trong B2B SEO/Ads market VN khi câu chuyện AI-augmented agency trở thành mainstream Q3-Q4 2026.
Null #2
Famous AI-using CEO talk AI generically — không name Claude Code
Houston, Collison, Naval, Andreessen, Altman đều talk về AI adoption công khai, nhưng không attribute Claude Code specifically. Houston (Semafor) quote về board memo "thought partner" — workflow real, tool attribution weak. Implication: narrative "F500 CEO uses Claude Code" thực tế NARROWER than headlines. Skeptical media spin về adoption sẽ đúng hơn nếu chỉ count first-person attribution.
Null #3
Non-engineer adopters skew indie/journalist, không F500
Mullenweg (Automattic ~2000 distributed), Newton (~3 ppl Platformer), Levels (solo), Lavingia (Gumroad ~10 ppl). Pattern: laptop-as-work-surface, không corporate IT stack. Implication: SEONGON cần thiết kế adoption workflow cho mid-large agency với corporate IT — khác với pattern indie có sẵn. Bài học từ indie pattern transferable nhưng không 1-1 copyable.
